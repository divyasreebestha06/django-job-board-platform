# 💼 django-job-board-platform

[![Python](https://img.shields.io/badge/Python-3.11-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://python.org)
[![Architecture](https://img.shields.io/badge/Pattern-Clean_Architecture-green?style=for-the-badge)](jobs/)

Applicant Tracking & Career Portal Backend with job postings, resume applicant models, and role permissions.

## Core Features
- **Job Posting Management:** Company listings, salary bands, and remote designations.
- **Applicant Tracking System (ATS):** Candidate resume ingestion and submission statuses.
- **Modular Architecture:** Decoupled service layer and request controllers.
